Procedural BGM 引擎

純演算法（即時合成，無取樣音檔、無 AI）：風格 preset → 分軌 / 樂器 / motif / groove 可再手調。

🎲＝保留設定，只換亂數種子。motif 模式下＝換一句新主題。下個循環生效。
⬇ MIDI＝把目前設定的 8 小節輸出成標準 .mid 檔（純音符、無音色、你的原創）。分軌會對到 GM 樂器：pad→弦樂、lead→依所選、bass→bass、drum→打擊(第10軌)。
同種子 + 同設定 → 生出完全一樣的旋律（可重現）。留空／改動後下個循環生效。
風格 Preset
用 VS Code Live Server（或任何 http 伺服器）開本頁 → 自動載入同資料夾的 styles.json。 按上面按鈕會下載一份合併好的 styles.json（含所有自訂風格），把它放回本資料夾覆蓋即可。
分軌控制
軌啟用樂器音色音量說明
音色為即時合成，帶電子質感，非真樂器錄音。要真木吉他/鋼琴音色需改用取樣音檔（sample），此版不含。
作曲參數
Motif＝先生成一句短動機，再重複+變奏+移調，聽起來有主題；漫步＝每音擲骰亂走。Groove 決定節奏語彙：鄉村搖擺會把貝斯做成「根音-和弦」的 boom-chick 感。
快＝緊湊推進；慢＝鬆、冥想。
大＝音密旋律明顯；小＝留白空靈。motif 模式下影響變奏時的裝飾音多寡。
長＝綿延重疊；短＝顆粒分明 staccato。
大＝飄遠空間深；小＝乾貼近清楚。
調性＝情緒色彩。色彩：add9 懸而未決；三和弦乾淨（鄉村常用）；power 厚重戰鬥。
